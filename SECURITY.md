# Security Policy

Synaptic Chat takes security seriously. It handles WhatsApp Business conversations, contact data, and encrypted Meta access tokens.

## Reporting a Vulnerability

Please report security issues privately by email to:

> **vtdhilipkumar@gmail.com** — subject line: `SECURITY: <short summary>`

To help triage quickly, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce it.
- Any proof-of-concept code, requests, or screenshots.

## Supported Versions

Security fixes are applied to the latest released version and the `main` branch.
